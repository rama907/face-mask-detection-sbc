# Dataset

The training images are **not included** in this repository. They are photos of real people, and redistributing them is not appropriate here.

The dataset used for this project has 4,095 images in two classes, with the following layout:

```
dataset/
  with_mask/      (2,165 images)
  without_mask/   (1,930 images)
```

The same dataset is published with the original open-source project this repository builds on:
https://github.com/chandrikadeb7/Face-Mask-Detection/tree/master/dataset

That project lists its image sources (Kaggle datasets and the RMFD real-world masked face dataset). Check each source's license before reusing the images.

To retrain, place your images in the folders above.
